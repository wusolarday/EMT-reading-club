救護技術員的「儀表板」— 點擊下方任一項目，即可展開完整內容（含 GCS 評分表、血壓參考表、異常呼吸型式等）。

生命徵象為意識（昏迷指數）、呼吸、脈搏、血壓、瞳孔、體溫、膚色及血氧濃度等八項，均為人體生理狀況呈現之表徵，救護技術員可藉此評估，作為病人病情危急度判斷之依據，也是送醫照護時重複評估病人該有的步驟。

經由生命徵象來瞭解傷患的生理狀況，俾能早期發現病人病情的變化。

數字記憶：
  • 呼吸 10–20 次/分；脈搏 60–100 次/分
  • 潮氣量 300–700 mL（6–8 mL/kg）
  • 正常血壓 < 120 / < 80 mmHg
  • SpO₂ < 94% = 供氧不足
  • 核心體溫 ≥ 38°C = 發燒；< 35°C = 低體溫
  • GCS ≤ 8 分 = 意識昏迷
關鍵警訊組合：
  • 溼冷蒼白 + 脈搏快 → 休克
  • 意識不清 + 瞳孔不等大 → 顱內病變
  • SpO₂ 正常 + 火災 CO 暴露 → 不可信任數字
  • 瀕死式呼吸 → 即將心跳停止
  • 三角架姿勢 → 下呼吸道阻塞
  • 姿勢性低血壓（站起 SBP↓≥20）→ 跌倒風險
